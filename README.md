# 오프라인 번역 (아이폰 홈 화면 앱)

한국어 ↔ 영어·일본어·중국어·베트남어·몽골어·스페인어. 처음 한 번 번역 모델(Meta NLLB-200 600M, 8비트 · 약 0.9GB)을 받아 아이폰에 보관하고, 그 뒤에는 **인터넷 없이** 아이폰 안에서 번역합니다. 번역하는 글은 밖으로 나가지 않습니다.

- 번역 모드: 입력하면 0.7초 뒤 자동 번역 · ⇄ 바꾸기 · 🔊 읽어 주기(그 언어 음성이 아이폰에 있을 때) · ☆ 남기기
- 대화 모드: 아래는 나(한국어), 위는 상대(화면이 뒤집혀 마주 보고 읽음). 말로 하려면 키보드 🎤 받아쓰기
- 시험: `node tests/text.test.mjs` · 화면 `node tests/web.test.cjs`(playwright)
- 엔진: transformers.js 3.8.1 (Apache-2.0, `app/vendor/`)
