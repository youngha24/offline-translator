# 오프라인 번역 (아이폰 홈 화면 앱)

한국어 ↔ 영어·일본어·중국어·베트남어·몽골어·스페인어. 처음 한 번 번역 모델(Meta NLLB-200 600M, 8비트 · 약 0.9GB)을 받아 아이폰에 보관하고, 그 뒤에는 **인터넷 없이** 아이폰 안에서 번역합니다. 번역하는 글은 밖으로 나가지 않습니다.

- 번역 모드: **자동 감지**(한국어 → 고른 외국어 · 외국어 → 한국어) · 문장을 끝맺으면 바로, 쓰는 중이면 0.6초 쉬면 번역 · 문장마다 끝나는 대로 보여 줌 · 같은 문장은 기억해 둔 번역을 바로(최근 400개) · 고쳐 쓰면 옛 요청은 버림 · ⇄ 바꾸기 · 🔊 읽기 · ⧉ 복사(번역문 눌러도) · ⤴ 공유 · ☆ 남기기(하나씩·모두 지우기) · «가» 글자 크게
- 대화 모드: 아래는 나(한국어), 위는 상대(화면이 뒤집혀 마주 보고 읽음) · «자동🔊» 켜면 번역되자마자 읽어 줌 · ✕ 대화 지우기. 말로 하려면 키보드 🎤 받아쓰기
- 시험: `node tests/text.test.mjs` · 화면 `node tests/web.test.cjs`(playwright)
- 엔진: transformers.js 3.8.1 (Apache-2.0, `app/vendor/`)
